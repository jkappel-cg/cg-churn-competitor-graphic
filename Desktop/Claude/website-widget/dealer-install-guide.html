CarGurus SMC Widget v1.0

Installation guide for dealership websites

🚀 Quick Start

Choose your implementation method and copy the code below:

Option A: Full-Width Blade (Recommended)

Embeds directly into your page as a section. Perfect for homepage or dedicated "Sell Your Car" pages.

<!-- Place this where you want the widget to appear --> <div id="cargurus-smc-widget"></div> <script src="https://widgets.cargurus.com/smc/widget-embed.js" data-dealer-id="YOUR_DEALER_ID" data-dealer-name="Your Dealership Name" data-theme="dark" data-flow="detailed"> </script>

Option B: Modal/Popup

Displays a button that opens the widget in a modal overlay. Great for navigation bars or CTAs.

<!-- Place this where you want the trigger button --> <div id="cargurus-smc-widget"></div> <script src="https://widgets.cargurus.com/smc/widget-embed.js" data-dealer-id="YOUR_DEALER_ID" data-dealer-name="Your Dealership Name" data-mode="modal" data-button-text="Get An Offer" data-theme="dark" data-flow="quick"> </script>

⚙️ Configuration Options

Attribute Required Options Description
data-dealer-id Yes Your dealer ID Unique identifier provided by CarGurus
data-dealer-name Yes Text string Your dealership name (e.g., "Riverside Motors")
data-theme No dark | light Color theme (default: dark)
data-flow No detailed | quick Number of steps (default: detailed)
data-mode No inline | modal Display mode (default: inline)
data-button-text No Text string Modal button label (modal mode only)

💡 Best Practices

  • Dark theme: Works best on light-colored pages or as a standalone hero section
  • Light theme: Ideal for pages with darker backgrounds or existing content
  • Quick flow: Recommended for mobile-heavy traffic (fewer steps = higher completion)
  • Detailed flow: Recommended for desktop or when you want more vehicle data upfront
  • Modal mode: Great for adding to existing pages without layout disruption

🔧 Troubleshooting

  • Widget not appearing? Check that your dealer ID is correct and the container div exists
  • Styling conflicts? The widget uses an iframe to prevent CSS conflicts
