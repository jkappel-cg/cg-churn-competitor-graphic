📋 Product Overview

💡 What It Is

  • → Embeddable SMC widget for dealer websites
  • → Runs on dealer's own domain (not marketplace)
  • → Uses dealer's existing SMC matrix & lead routing
  • → Branded as "Powered by CarGurus"
  • → No separate pricing system to manage

🎯 Who It's For

  • Primary: Existing SMC dealers who want:
  • • More consumer-sourced vehicles
  • • Alternative to KBB ICO / TrueCar widgets
  • • To consolidate vendor solutions
  • Internal: SMC Sales & PS teams
  • • Position as upgrade/add-on
  • • Drive stickier SMC adoption

🔥 Why It Matters

  • → Dealers explicitly requested this functionality
  • → Expands SMC beyond CG marketplace traffic
  • → Captures dealer's own website visitors
  • → Improves SMC retention & perceived ROI
  • → Reduces early SMC churn
  • → Competitive alternative to KBB (~$8K/mo)

📍 Where It Lives

  • Standalone Page: /sell-your-car
  • Homepage Blade: Hero or footer section
  • Modal Popup: Nav button trigger
  • Service Pages: Service lane upsell
  • Marketing: Email, social, paid ads

⚙️ How It Works

  • 1. Dealer copies embed code snippet
  • 2. Pastes into their website CMS
  • 3. Widget loads with dealer's SMC config
  • 4. Consumer enters vehicle details
  • 5. Instant offer via dealer's matrix
  • 6. Lead flows to SMC dashboard + CRM
  • 7. Tagged as "website widget" source

💰 How We'll Sell It

  • Positioning:
  • • "SMC Plus" or "SMC Premium" tier
  • • Bundle with marketing assets
  • • Natural upgrade for existing SMC
  • Value Props:
  • • More leads from same subscription
  • • Replace expensive KBB/TrueCar
  • • Increase switching costs
🎯 Success Metrics:
• Widget adoption rate by SMC dealers
• Incremental leads per dealer
• SMC retention improvement
• KBB/TrueCar replacement wins
• Time to first widget lead
• Widget → purchase conversion
